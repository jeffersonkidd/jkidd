# PRODUCTION SPECIFICATION FOR COLLECTIBLE RETRO POSTCARD SERIES

## PURPOSE

PRODUCE **THE NEXT POSTCARD IN AN EXISTING COLLECTIBLE SERIES.**

THE SUPPLIED REFERENCE IMAGE IS **THE CANONICAL MASTER** FOR THE SERIES.

THIS IS **NOT** A REQUEST TO IMITATE A STYLE.

THIS IS A REQUEST TO CREATE **THE NEXT ILLUSTRATION PRODUCED BY THE EXACT SAME ARTIST, USING THE EXACT SAME PRODUCTION PROCESS, COLOR INKS, TYPOGRAPHY SYSTEM, PRINT PROCESS, AND LAYOUT SYSTEM.**

ASSUME EVERY POSTCARD WILL ULTIMATELY BE DISPLAYED ADJACENT TO EVERY OTHER POSTCARD IN THE COLLECTION.

ANY VISUAL DIFFERENCES THAT IMPLY A DIFFERENT ILLUSTRATOR, PRINTER, DECADE, RENDERING ENGINE, OR COLOR PROCESS SHOULD BE CONSIDERED PRODUCTION DEFECTS.

---

# HIERARCHY OF REQUIREMENTS

## PRIORITY 1

MAINTAIN PRODUCTION CONTINUITY WITH THE SUPPLIED REFERENCE.

EVERYTHING ELSE IS SECONDARY.

THEME CHANGES.

PRODUCTION DOES NOT.

## PRIORITY 2

MAINTAIN IDENTICAL VISUAL DNA.

TREAT THE FOLLOWING AS FIXED ASSETS:

- CANVAS DIMENSIONS
- MARGINS
- BORDER
- PAPER COLOR
- PAPER AGING
- DISTRESS PATTERN
- INK DENSITY
- PRINT TEXTURE
- HALFTONE TREATMENT
- LINE WEIGHT
- CEL SHADING
- SHADOW CONSTRUCTION
- HIGHLIGHT TREATMENT
- TYPOGRAPHY CONSTRUCTION
- EXTRUSION DEPTH
- LETTER SPACING
- PERSPECTIVE
- ILLUSTRATION DENSITY

## PRIORITY 3

ONLY REPLACE NARRATIVE CONTENT.

EVERYTHING THAT DEFINES THE POSTCARD'S IDENTITY REMAINS.

ONLY REPLACE:

- THEME
- SCENERY
- PROPS
- ENVIRONMENTAL STORYTELLING
- ICONS INSIDE LETTERING

---

# COLOR SYSTEM

THE SUPPLIED REFERENCE DEFINES THE CANONICAL PALETTE.

DO NOT REINTERPRET IT.

DO NOT IMPROVE IT.

DO NOT BRIGHTEN IT.

DO NOT MUTE IT.

DO NOT SHIFT ITS WARMTH.

DO NOT INCREASE SATURATION.

DO NOT DECREASE SATURATION.

TREAT THE REFERENCE AS DEFINING A FIXED INK LIBRARY.

REUSE THE SAME RELATIONSHIPS FOR ORANGE, CREAM, CYAN, TEAL, BROWN, BLACK, OLIVE, AND ACCENT RED.

THE GOAL IS THAT MULTIPLE POSTCARDS APPEAR TO HAVE BEEN PRINTED FROM THE SAME PRESS USING THE SAME INKS.

---

# COLOR DISTRIBUTION

REUSE BOTH THE COLORS **AND THEIR PROPORTIONS**.

KEEP THE OVERALL BALANCE BETWEEN ORANGE, CREAM, CYAN, BLACK, AND DARK TEAL VISUALLY CONSISTENT WITH THE MASTER.

---

# TYPOGRAPHY

TREAT THE LETTERING AS A REUSABLE PRODUCT ASSET.

MAINTAIN IDENTICAL:

- THICKNESS
- EXTRUSION
- OUTLINE WIDTH
- BEVEL
- SHADOW
- PERSPECTIVE
- CURVATURE
- INTERNAL ILLUSTRATION STYLE

ONLY REPLACE THE TEXT.

---

# ILLUSTRATION STYLE

MAINTAIN:

- BOLD COMIC OUTLINES
- SIMPLIFIED FORMS
- FLAT CEL SHADING
- MINIMAL GRADIENTS
- LIMITED RENDERING
- VINTAGE COMIC PROPORTIONS
- GRAPHIC READABILITY

AVOID:

- PAINTERLY RENDERING
- REALISTIC ANATOMY
- CINEMATIC LIGHTING
- EXCESSIVE DETAIL
- AIRBRUSHED SURFACES

---

# PRINT CHARACTERISTICS

MAINTAIN IDENTICAL:

- PAPER TEXTURE
- PAPER AGING
- HALFTONE FREQUENCY
- INK TRAPPING
- DISTRESS AMOUNT
- GRAIN
- EDGE WEAR

---

# COMPOSITION

1. TYPOGRAPHY DOMINATES.
2. BACKGROUND SUPPORTS TYPOGRAPHY.
3. DECORATIVE STORYTELLING FILLS REMAINING SPACE.

---

# VARIATION POLICY

MAXIMUM ALLOWABLE VARIATION:

- SUBJECT MATTER
- SCENERY
- NARRATIVE
- ICONS
- ENVIRONMENTAL STORYTELLING

MINIMUM ALLOWABLE VARIATION:

- PRODUCTION
- RENDERING
- COLOR SYSTEM
- TYPOGRAPHY
- PRINT CHARACTERISTICS
- LAYOUT
- GRAPHIC LANGUAGE

---

# QUALITY CONTROL CHECKLIST

BEFORE CONSIDERING THE IMAGE COMPLETE:

- WOULD BOTH POSTCARDS APPEAR PRINTED USING THE SAME INKS?
- WOULD THEY APPEAR ILLUSTRATED BY THE SAME ARTIST?
- WOULD THEY APPEAR PRODUCED DURING THE SAME PRINT RUN?
- WOULD THEY APPEAR SOLD TOGETHER AS THE SAME COMMERCIAL POSTCARD SET?
- WOULD A COLLECTOR IMMEDIATELY BELIEVE THEY BELONG TO THE SAME SERIES?

IF ANY ANSWER IS "NO," CONTINUE REFINING.

---

## GUIDING PRINCIPLE

TREAT THE SUPPLIED POSTCARD AS THE **SERIES MASTER**.

PRESERVE EVERY VISUAL CHARACTERISTIC THAT IS **NOT EXPLICITLY REQUESTED TO CHANGE**.

DEFAULT TO COPYING PRODUCTION DECISIONS RATHER THAN INVENTING NEW ONES.

WHEN UNCERTAINTY EXISTS, RESOLVE IT BY MATCHING THE REFERENCE INSTEAD OF EXERCISING CREATIVE DISCRETION.

THE CREATIVE TASK IS TO INVENT A NEW NARRATIVE USING AN EXISTING VISUAL SYSTEM—NOT TO INVENT A NEW VISUAL SYSTEM.
